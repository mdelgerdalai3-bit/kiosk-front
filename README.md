# ОЮУНЛАГ — Гадаадад суралцагчдын 3D Globe

[cobe.vercel.app](https://cobe.vercel.app/)-ийн polaroid хувилбараар санаа авсан **Next.js (App Router)** төсөл.
Эргэлддэг WebGL глоб дээр сурагчид суралцаж буй улсуудыг тэмдэглэж, тухайн байршилд **polaroid карт** наана.

## Боломжууд
- 🌍 COBE WebGL глоб (брэнд өнгөтэй)
- 📍 Улс орон бүрийн координат дээр **байршдаг** polaroid карт (глоб эргэхэд хамт хөдөлж, ар тал руу орвол алга болно)
- 🖐 Чирж эргүүлэх (drag) · 🔍 ＋ / － / ⟳ товч болон хулганы дугуйгаар zoom
- Доор нь улсуудын жагсаалт, сурагчдын тоо

## Ажиллуулах
```bash
npm install
npm run dev
```
Дараа нь хөтөч дээр **http://localhost:3000** руу орно.

Production:
```bash
npm run build && npm start
```

## Өгөгдөл засах
`data.js` доторх `COUNTRIES` массивыг засна:
```js
{ name: "АНУ", city: "Нью-Йорк", flag: "🇺🇸", n: 14, loc: [40.71, -74.00] }
//                                              сурагч        [lat, lng]
```

## Тэмдэглэл
Polaroid-ийн байрлал глобын эргэлттэй ойролцоо тааруулагдсан. Хэрэв шошго маркераас бага зэрэг
зөрвөл `app/globe.js` доторх projection (`positionPins`) дахь `R*0.92` коэффициент эсвэл
`PHI0` эхлэлийн өнцгийг тааруулж болно.
